# .github

Organization-level GitHub configuration for [Whelk](https://www.getwhelk.com).

- `profile/README.md` renders on [github.com/getwhelk](https://github.com/getwhelk). This repo must stay public for it to appear, even though the product repos are private.

Anything added here (issue templates, workflow templates, `CODEOWNERS`) applies org-wide as a default, and any repo that defines its own version overrides it.
